# Replication Package

**Paper:** Transfer Learning for Differentiable Causal Discovery: Warm-Starting NOTEARS, DAGMA, and GOLEM with Cross-Dataset Causal Graphs  
**Author:** Shuaidong Gao  
**Journal:** Journal of Bioinformatics and Computational Biology (JBCB), submitted  
**Date:** July 2026  

---

## Quick Start

```bash
# 1. Validate pre-computed results (~1 minute, no GPU needed)
python run_all.py

# 2. Regenerate figures from cached results (~30 seconds)
python run_all.py --figures

# 3. Compile the manuscript to PDF
python run_all.py --compile

# 4. Full reproduction from scratch (~6 GPU-hours)
export TCGA_DATA_DIR=/path/to/tcga/data   # Set TCGA data location
python run_all.py --all
```

## Requirements

- Python 3.8+ with packages: `torch`, `numpy`, `scipy`, `matplotlib`, `pandas`
- For compilation: `pdflatex` + `bibtex` (TeX Live or MiKTeX)
- For full regeneration: NVIDIA GPU with CUDA (8 GB VRAM recommended)

```bash
pip install -r requirements.txt
```

## Data Availability

Pre-computed results are in `results/`. All tables in the paper can be validated without external data.

To re-run experiments from scratch, download the following public datasets:

1. **TCGA pan-cancer expression data** from [UCSC Xena](https://xenabrowser.net/)
   - HiSeqV2 pan-cancer normalized expression: `TCGA_XXX_HiSeqV2.tsv` for 33 cancer types
   - Place all `.tsv` files in a directory and set `TCGA_DATA_DIR`:
     ```bash
     export TCGA_DATA_DIR=/path/to/tcga_tsv_files
     ```

2. **DepMap CRISPR dependency data** from [DepMap Portal](https://depmap.org/)
   - `CRISPR_gene_effect.csv` (23Q2 release)
   - Place in the same `TCGA_DATA_DIR` directory

## Troubleshooting

**"CUDA not available"**: The scripts automatically fall back to CPU. Set `CUDA_VISIBLE_DEVICES=""` to force CPU mode.

**"TCGA data not found"**: Set the `TCGA_DATA_DIR` environment variable pointing to your TCGA `.tsv` files. Validation does not require TCGA data.

**"File not found: benchmark_v6_checkpoint.json"**: Ensure you are running from the repository root directory and the `results/` folder is intact.

**"pdflatex not found"**: Install TeX Live or MiKTeX. On Ubuntu: `sudo apt install texlive-full`. On macOS: `brew install mactex`.

**Figure generation fails**: Ensure `results/cache/` contains `src_d454.npy`, `warm_d454_s42.npy`, and `scratch_d454_s42.npy`. These are included in the package.
